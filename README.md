# Кампус СВФУ

Сайт объявлений для студентов СВФУ: поиск соседа по квартире, учебники и конспекты, подработка.
Работает без своего сервера: страницы лежат на GitHub Pages, объявления и вход — в бесплатном Supabase.

## Что внутри

| Файл | Зачем |
|---|---|
| `index.html` | страница сайта |
| `style.css` | оформление, светлая и тёмная тема |
| `app.js` | логика: лента, фильтры, форма, вход по почте |
| `config.js` | ключи Supabase и настройки |
| `supabase/schema.sql` | таблица объявлений и правила доступа |

Пока `config.js` не заполнен, сайт работает в **демо-режиме**: всё сохраняется только в вашем браузере. Так можно открыть `index.html` и посмотреть, как всё устроено.

## Запуск за 15 минут

### 1. База данных (Supabase)
1. Зарегистрируйтесь на https://supabase.com и создайте проект (New project). Регион — ближайший, пароль базы сохраните.
2. Откройте **SQL Editor → New query**, вставьте содержимое `supabase/schema.sql`, нажмите **Run**.
3. **Project Settings → API**: скопируйте `Project URL` и ключ `anon public` в `config.js`.

### 2. Вход по почте
1. **Authentication → Sign In / Providers → Email**: вход по почте включён по умолчанию, пароль не нужен (приходит ссылка).
2. **Authentication → URL Configuration**: в `Site URL` и `Redirect URLs` впишите адрес сайта, например `https://ваш-ник.github.io/kampus-svfu/`.
3. Встроенная почта Supabase отправляет всего несколько писем в час. Для реальной работы подключите свой SMTP (**Authentication → Emails → SMTP Settings**) — подойдёт Яндекс Почта для домена, Mail.ru или Resend.

### 3. Хостинг (GitHub Pages)
1. Создайте репозиторий `kampus-svfu` на https://github.com и загрузите в него все файлы.
2. **Settings → Pages → Source: Deploy from a branch → main / (root)** → Save.
3. Через минуту сайт откроется по адресу `https://ваш-ник.github.io/kampus-svfu/`.

Свой домен (например `kampus-svfu.ru`) подключается там же, в **Settings → Pages → Custom domain**.

## Только для студентов

Чтобы размещать объявления могли только владельцы студенческой почты:
Уже включено: публиковать объявления можно только с почты `@stud.s-vfu.ru`. Читать объявления может любой посетитель.

Проверка стоит в двух местах: в `config.js` (подсказка на сайте) и в `schema.sql` (защита в базе). Проверка в базе обязательна: без неё ограничение на сайте легко обойти.

Чтобы разрешить любую почту: очистите `ALLOWED_EMAIL_DOMAINS` в `config.js` и удалите строку с `stud.s-vfu.ru` в `schema.sql`, затем снова выполните файл.

## Как устроена защита
- Читать объявления может любой посетитель, публиковать — только после входа по почте.
- Снять или изменить объявление может только его автор (правила Row Level Security в базе).
- Не больше 10 объявлений в сутки с одного аккаунта.
- Объявления старше 60 дней скрываются из ленты. Автоудаление из базы — по желанию, см. конец `schema.sql`.
